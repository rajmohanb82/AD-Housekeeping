Deployment

Apache Tomcat on a member server

Directory Keep is a Python service. Apache Tomcat 10.1 is the front door you deploy in Active Directory: a private-network context on a Tier-1 server, running as a group managed service account that is not a Domain Admin.

  1. Member serverWindows Server already joined to fabrikam.corp. The installer does not join a domain for you.
  2. Tier-1 OUPlace the host in the servers OU, not the domain controllers OU.
  3. gMSAsvc-adhk$ runs Tomcat and the Python service. It can reset and unlock in the people OU only.
  4. Tomcat 10.1Context /ad-housekeeping on port 8080, limited to private addresses.
  5. Python serviceWaitress on 127.0.0.1:8765. Tomcat links operators to it.
